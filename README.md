# Hastane Otomasyonu (C# & MySQL)

Bu proje, bir hastanenin temel operasyonel süreçlerini (randevu, hasta işlemleri ve yönetim paneli) yönetmek amacıyla C# ve MySQL kullanılarak geliştirilmiştir.

### Kullanılan Teknolojiler:
* **Dil:** C# (Windows Forms)
* **Veritabanı:** MySQL
* **Geliştirme Ortamı:** Visual Studio 2022
